# sipeed-rvmonitor

A small C terminal monitor for the Sipeed Lichee RV Nano (SG2002).
It tracks the Linux C906, auxiliary C906L running FreeRTOS, and NPU command activity.

The import is being organized into feature commits from saved development snapshots.
Commit timestamps record this publication, not fabricated historical development dates.
